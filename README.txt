CELESTE English School — Interchange Basic Exam

Folder structure (audio and images are beside index.html, NOT inside exam/):
index.html
README.txt
audio/       listening MP3 files
images/      question image files
exam/        eight exam HTML pages

Open index.html in a browser. The exam HTML files reference shared media using ../audio/filename.mp3 and ../images/filename.png because the exam pages are inside exam/.

Add your actual MP3 recordings to audio/ using the exact filenames listed in audio/README.txt. The source PDFs did not include audio recordings, so those MP3 files are not bundled.


Answer checking: answers are matched without case sensitivity and allow common English contractions (for example, “it’s” / “it is”) and common number words/digits (for example, “fifty” / “50”). Responses are still checked against the intended answer; alternative wording is not accepted automatically unless covered by the question-specific rules.
